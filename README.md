# GLR Sparse-Seq

Community (unofficial) implementation of **"Gated Latent Routing for Sparse Sequence Models"**
(technical note FSP-2026-0417).

This repository is maintained by the community and is not affiliated with the authors of the
note. It contains a C++ reference port of the gated latent routing layer described in the
technical note.

## Status

- independent community port
- validated on synthetic routing benchmarks
- no official code was available when this port was written
